Что такое шаблон

Шаблон — это сохранённый набор данных для документов: имя клиента, число занятий, цены, период, примечание, доп. аренда, номер, дата и способ оплаты, статус. Один и тот же шаблон заполняет и абонемент, и чек об оплате.

Поля можно править прямо на сайте в разделах «Абонемент» и «Чек». Либо скачать файл template.json, изменить его и загрузить обратно.

Что внутри файла

  • client — имя клиента
  • lessons — количество занятий
  • price — цена за занятие
  • currency — валюта (₺ € $ ₽)
  • from / until — период действия
  • note — примечание / направление
  • equipment — что в доп. аренде
  • equipmentPrice — цена доп. аренды
  • equipmentQty — количество по аренде (в чеке)
  • number — номер документа
  • paidAt — дата оплаты
  • paymentMethod — способ оплаты
  • paymentStatus — статус (например, «Оплачено»)
  • serviceLabel — название услуги в чеке
  • visits — отметки занятий на абонементе

Кнопки

  • Скачать — сохраняет текущие поля в браузере и скачивает template.json на компьютер.
  • Загрузить — выбираешь свой template.json с компьютера и подставляешь данные в документы.
  • Загрузить с сайта — берёт template.json из проекта / с GitHub Pages.
  • Пустой шаблон — очищает поля, чтобы начать с чистого листа.
